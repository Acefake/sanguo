# 世界地图顶层界面

界面装饰、头像环、圆形进行按钮、功能图标、页签均来自用户指定的三国志14_UI素材/布局还原。原始路径记录于 sources.json。

world_map_hud.gd 负责左上君主、当前日期、命令数、领地城池数量及右上派遣状态。进行按钮接 CampaignUI 时间推进，右上工具保留地图显示开关、城池/关口跳转、画质及2D切换。军报和设置接现有页面。原型暂无爵位等级数据，所以圆形等级区域显示实际城池数量。

头像继续使用项目的三国志8 REMAKE肖像资源，按当前玩家势力选择。刘备使用 face_0052_00 的头像裁切。普通主按钮使用用户提供的正常/高亮两张图，统一从 CitySkin 及默认 Theme 应用。

已移除三维地图旧顶栏、底部帮助条及左下格子调试显示；格线、点选和路径逻辑保留。
