# 城池与场景逐城核对表

原始 51 城的对应已用解码后的城市表、州表逐条校验。当前地图有 70 城；长安按用户要求单独覆盖为都城布局，其他 42 城直接对应原城市、1 城使用名称别名、26 城采用明确配置的参照城。原数据用于追溯，不限制本项目的城市美术配置。

场景按城市 ID 指定，不跟随势力变更，也不按大地图州名兜底。城市外观覆盖优先于原版分类；原版五类城景允许同类城市共享布局。
