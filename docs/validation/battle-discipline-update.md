# 战斗行动稳定性修复

2026-10-04。修复前25日小沛离线复现：魏延与文丑侧翼接战期间仍逐日绕行，文丑第5至6日原路折返；魏延从侧翼调任主攻后仍被旧列约束锁在战场边缘。普通主攻与侧翼持续追赶溃退敌军，中军和预备队不跟进前线。

本轮改动：

- 已接战部队原格交战，不再一边近战一边绕圈；撤退与归建仍受包围、脱离准备和离战损失规则约束。
- 普通侧翼分阶段绕行：固定一处可通行绕行点，敌军普通移动不重新计算该点。到点或接战后进入攻击阶段。
- 保持观察到的目标四日；当前目标结束或出现贴身威胁时重选。失去有效观察的旧军令不会读取未知敌军位置。
- 普通追击最多离开接战起点三格，并尊重禁止追击军令。明确独立奇袭、断粮不套用普通追击限制。
- 普通任务至少执行三日，重复相同任务不重置阶段。紧急掩护、归建、全军撤退可越过普通换令限制。重新任职时更新阵线列，清除旧侧翼阶段和旧寻路往返记忆。
- 不提供或接受把最后一支主攻改为侧翼、预备或独立奔袭的命令；接战部队不能直接改为独立奔袭。
- 中军和预备队依当日起始前线快照跟进，保留三行纵深与一格停止余量，避免按移动顺序逐支追赶移动中的锚点。
- 掩护队位于撤退友军靠敌的一侧，接战后守住掩护位置。
- 目标未变时，遇临时阻塞先等待，避免连续两步原路折返；连续受阻两日后允许绕障。

验证：新增 `tests/battle_discipline_validation.gd`，覆盖六日侧翼近战原格保持、固定绕行点、目标保持与近身威胁优先、调任重设阵线、换令承诺、紧急掩护、三格追击限制及三十日241次有效格占用检查。战争、军令、军团、包围、全局格、小沛、后台决策回归通过；小沛3D加载和战斗截图检查通过。

`battle-motion-after.json` 是修改后的25日离线轨迹，无进攻部队连续两步原路折返。末期正常撤退、受阻后绕障和接近后进入近战仍允许移动；没有把所有移动都判成错误。离线轨迹验证规则行为，不证明任何外部模型的战术质量。
