# 小沛军团与攻城更新

小沛测试默认开场为两支完整军团，每方 20000 人，共 18 名现有武将随军。主帅从均衡、加强前锋、加强侧翼三种初始部署中选择，再按人物位置与能力生成双前锋、侧翼、预备和中军；后续允许继续派遣奇袭或断粮小队。兵力、兵种、粮食由实际军团库存划拨。

攻城遵循全局格子位置：先解决野战屏障，再分配稳定的城下集结位置。前锋和侧翼在两格范围部署，中军与预备在三格范围支援；至少 75% 的可用攻城兵力到位才进入强攻。野战尚未结束时，单独接近城市的侧翼不会自行攻城。准备、围困、强攻、援军阻断、占领均保留状态，城墙和守军士气持续结算。主帅可选择围困或强攻。破城后实际划拨驻军，统计伤亡与俘虏，并执行战后军令。

- local_agent_live --simulate：实际 Ollama Qwen3:1.7b，think=false，两位主帅返回两条合法 deploy_corps 决策。本次请求共 13726ms；模拟期间本地策略先部署，两条晚到模型方案被安全丢弃。每日逻辑 10/114/111ms，无格子重叠。这不是完整 3D 帧率或速度保证。
