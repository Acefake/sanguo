# 主格子系统统一

2026-10-04。删除 `army_world_3d.gd` 的 `_draw_obstacles` 及其局部 `ImmediateMesh` 格线。粮道标签保留为独立标签，未再创建战斗格线网格。

`rtk14_hex_grid.gd.shared()` 提供同一个全局格子对象，供3D主地图、2D主地图和战斗规则使用；数据加载幂等。战斗的全局格中心、六邻接、距离、不可通行判断及动态占位寻路由主格子服务提供。战斗用每次调用的占位表寻路，不修改主地图路径预览的缓存AStar节点，避免互相污染。小沛预设的交战范围只是移动边界，未创建另一张格子地图。

3D主地图的选格信号接入军队详情：普通点击军队所在格打开本方详情或已知敌情，Shift路径预览继续由主地图负责。G只控制主地图材质格线，战斗没有单独绘制层。

验证：主格数据、3D倾斜摄像机拾取与路径、全局战斗位置、包围、军团、战斗纪律回归通过。实机小沛测试断言地图与战斗共享对象、无残留局部格线Mesh、主格点击接通军队详情及主格线开关有效。更新截图 `army-assets/xiaopei-battle.png`。
