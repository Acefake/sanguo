# 全国大地图 · 数据与素材

2026-10-01 根据用户要求从中原五州扩展为全国战略图。当前包含 13 个州区、70 座城池、2 处关隘、96 条通路、21 个演示势力。主场景与城内系统继续共用 GameState。

## 当前显示

- 城池采用与参考图 2 相近的白色盾形轮廓，顶部细色带表示归属；放大后显示势力简称。关隘仍用城门图标。
- 城池对应的领地从州区内邻近城市分区后裁切，颜色读取剧本当前归属。同一州可以同时包含不同势力。
- 无主区域默认保留灰淡地形，盾牌色带为灰白；顶部可切换灰白填色进行比较。灰白方案仍能看见山川纹理。
- 势力名放在当前控制的领地内，并尝试避开城池与已显示名称；总览只显示主要城名，放大后显示全部城名。
- 通过势力／地形切换和完整图例查看不同层次。势力标签、领地颜色、盾牌色带、详情面板随 city_changed 刷新。

## 地理与剧本边界

本版是美术布局及交互原型，城市显示位置、州界和通路不是测绘坐标，势力并不对应单一历史年份。城池邻近分区用于表现控制范围，不是历史郡界。路线权重用于寻路演示，不能直接当作最终行军天数。

后续史地校核可参考[CHGIS 项目](https://chgis.fas.harvard.edu/pages/intro/)的历史地名与行政区资料；本次没有直接导入该数据库。
