# 军队 3D 素材与接入说明

当前地图按主兵种显示固定阵列：步兵64人、弓兵64人、骑兵36骑。兵力变化只更新部队数字与结算账本，不增减展示模型。阵列带军旗，脚边显示透明半身立绘、队号、兵力和分段士气条。点击本方部队可查看详情与军令；敌军只显示已发现的情报与估计，不能操作。未知主帅使用旗帜标识，不猜测姓名与立绘。

军令包含敌军接近时攻击或无视、自主撤退许可、追击许可、攻取后撤退或待命。主动撤退沿合法路线返回友城，归营回收兵力与粮草。战役中城池占地、完整敌城墙体、友城城门和破口参与通行约束。

默认1倍速度每个游戏日的行军与交战展示为3.6秒，保留2倍、4倍与暂停。步兵与战马使用已经解码的原生G2A待机、行军和攻击动作；骑手使用原生步兵模型，骑乘坐姿由项目调整。弓兵的持弓和射击姿态仍为项目制作。模型通过MultiMesh与GPU姿态贴图播放，多个单位错开动作相位。

城防不再放置会闪现的城头士兵，直接从城墙锚点向有效敌军发射原生箭矢。城防射程从城墙向外计算两格，野战远射为两格，三格不能命中；近战仍为相邻格。每个实际齐射事件播放两轮慢速飞行，不重复扣兵。粗白箭束已移除。近战使用原生扇形纹理，弧边朝目标展开，播放周期放慢为1.85秒。

最新画面、来源与验证范围见[战斗模型与动画重构](战斗模型与动画重构-2026-10-06.md)。

## 可复用文件

- `assets/armies/rtk14/manifest.json`：原模型、材质引用、用途与恢复状态。
- `assets/armies/rtk14/field_animation_sources.json`：原生动作哈希、姿态分组与制作边界。
- `assets/armies/rtk14/models/infantry-poses.glb`、`cavalry-poses.glb`：各29帧原生动作烘焙资源。
- `assets/armies/rtk14/models/arrow.glb`：方向校正后的原生带贴图箭矢。
- `data/officer_portraits.json`：已核对的姓名、原始路径和半身裁切范围。
- `tools/native_army_animation.py`、`rebuild_field_troops.py`：解码原生G2A动作并重建阵列模型。
- `tools/stage_native_arrow.py`：按原生材质引用重建箭矢。
- `tools/import_unit_portraits.py`：从已核对映射生成透明半身部队立绘。
