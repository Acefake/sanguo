# 城内 UI 元素与接入说明

## 2026-10-01 用户精灵图接入

官府底部现按用户选择改为“人事、军事、计略、外交、方针、谍报”。文字和配套符号共用第三张原始精灵图 `ui/user-atlas/council-labels.png`，`council_label_atlas.gd` 与 `council-labels-regions.json` 指定显示区域，不导出独立位图。字形描边周围留出透明边距，各状态居中对齐；原普通字体及旧分类图标不再叠加。“进行”替换官府中的月末按钮文字，离开官府恢复“结束本月”。

方针沿用安民、开垦、征税；军事沿用征募、训练、城防。谍报连接城市情报与记录，外交可查当前势力控制城池、人口和兵力汇总。人事武将资料尚未录入，任免、计略、外交交涉尚未开放，对应指令明确禁用。购售粮草与锻造仍可从城内市场、工坊进入。

右上角六个菜单随后改为用户第二张精灵图中的完整圆形图标，原件为 `ui/user-atlas/toolbar-source.png`，显示坐标由 `scripts/toolbar_sprite_atlas.gd` 管理。依次对应大地图、城池情报、施政记录、设置、帮助、返回；保留原有功能与提示。普通、悬停、按下、禁用直接引用整图的对应区域，键盘焦点采用同图的镂空金色圆环。原标称 100×100 区域会裁掉外圈和下方阴影，现使用 106×108 的安全取样范围，加透明留白对齐为 112×112，避免带入邻近行的其他素材。按钮显示框为 40×40，圆形本身仍约 36×36；保留透明边缘并开启缩小过滤，不再叠加旧工具栏符号。建筑按钮继续使用第一张图中的八角底座。

当前按钮统一使用用户提供的 1200×700 精灵图，原件保存为 `assets/city/han/ui/user-atlas/source.png`。原件保持不变；`scripts/ui_sprite_atlas.gd` 记录切片坐标，在加载时对切片创建透明轮廓并缓存纹理。素材原有深灰底及压缩杂色不会作为按钮外部底块显示，深色按钮内部保留。

| 当前元素 | 精灵图对应区域 |
| --- | --- |
| 普通命令、地图操作、档案设置 | Borders 区的古金色矩形，配亮金悬停/按下、深灰禁用 |
| 政厅分类、结束本月、关闭 | Buttons 区的红色横按钮，选中分类使用亮金色 |
| 决定与返回 | Buttons 区的红色八角按钮，配橙红悬停/按下、深灰禁用 |
| 建筑按钮 | Buttons 区的小八角金属底座，配独立状态；语义符号单独叠加 |
| 右上工具栏 | 第二张精灵图的完整圆形菜单图标 |
| 官府分类与进行文字 | 第三张精灵图的字形、符号与状态配色 |
| 键盘焦点与建筑选中 | Borders 区的金色发光框及金属底座边缘 |
| 面板、标题及行动力 | Panels 区的浅色面板、暗红纹样栏、渐变条 |

矩形按钮采用九宫格缩放，保留切角和边缘。八角确认按钮等比显示；焦点层内部镂空，文字不会被遮挡。建筑与工具栏只保留原有图标中的功能符号，旧圆形按钮外壳已移除；文字、图标和资源数值仍由游戏独立显示。

`city_ui_skin.gd` 提供统一皮肤，城内、政厅、行动预览、档案和全国地图共用。`tests/ui_atlas_validation.gd` 检查切片越界、缓存、透明边缘、深色填充与状态切换；原有交互检查覆盖真实点击、确认/取消及分层返回。

## 前一版 UI 重构记录

人物已替换为用户新提供的透明立绘 `assets/city/han/officer-user.png`，原文件直接复制，未重绘。城内、政厅和行动预览头像共用此文件；头像使用 `AtlasTexture` 区域 `(300, 10, 470, 530)` 显示头肩。前期 `officer-v2.png` 保留但不再用于当前界面。

前一版依据用户四张高清参考采用 SVG 切角按钮、浅绢纸、暗红横栏及细金线图标。该版按钮与面板现已被用户精灵图替换。以下素材表记录旧版制作过程。

| 旧版元素 | 文件 |
| --- | --- |
| 浅绢纸与暗红标题栏 | `ui/paper-sheet.svg`、`ui/section-header.svg` |
| 分类与一般按钮 | `ui/flat-*.svg` |
| 决定、返回及焦点/禁用状态 | `ui/octagon-*.svg` |
| 建筑与工具栏细线图标 | `ui/marker-*.svg` |
| 政厅底部分类图标 | `ui/tab-*.svg` |
| 行动预览页面 | `scripts/city_action_view.gd` |
| 征兵页实拍 | `assets/city/han/action-preview.png` |

上述 SVG 为原生界面绘制；本次未生成新的场景或人物图片。行动页按消耗/结果分区，当前值、施行后值、变化量均读取 `GameState.preview_action()`。预览与执行共用同一效果函数，返回不扣资源，决定时再次检查行动条件。情报与施政记录改为整页档案。

`Esc` 先取消预览或关闭档案，再关闭事务菜单，从政厅返回城内，最后返回地图。

图标顺序：官府、市场、农田、兵营、工坊、酒肆、地图、城池情报、施政记录、显示设置、帮助、返回。

点击官府进入议事厅沙盘，底部“内政、军事、市集、工务、民情”打开对应命令，“返回城内”退出政厅。城内其他建筑保留附近的小型菜单；建筑按钮、工具栏、菜单和资源栏独立存在。

所有命令共用 `GameState`。人口、势力等读取当前城池，日期、行动力、行动记录读取游戏状态，图标反馈和按钮禁用由实时规则控制。`Esc` 先关闭弹窗或命令菜单，再从政厅返回城内，最后返回地图。

当前剧本、资源交易、军备与访察均为演示规则，势力归属及数值待目标历史年份校定。各城暂共用一套城景、政厅背景和参议形象；原背景、初版立绘及图标素材仍保留。

## 素材生成提示词

模式：内置 imagegen；风格来源为用户提供的两张城内参考截图。以下为本轮四份最终提示词的简短说明，生成空白装饰与独立美术，文字和操作由游戏界面叠加。

- **透明立绘**：原创汉末参议，半写实历史游戏绘画风格，朱红外袍、深色内衫、自然人物神态与细腻笔触，独立透明背景。
- **按钮图集**：六种空白古铜绢纸按钮，分别表现 normal、hover、pressed、disabled、primary、secondary，统一形状和纹理，不含文字。
- **绢纸窗**：空白浅色绢纸窗口，细铜边和铜角装饰，中心保持平静、适合叠加文字，独立透明边缘。
- **议事厅背景**：原创汉末建筑内的议事厅沙盘，木梁、屏风、案几与战略地形陈设，灰青与暖铜绘画色调，完整无 UI 场景背景。
