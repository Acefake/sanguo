# 小沛智能体对战测试

在主设置菜单点击“小沛中型对战 · 全武将出阵／重置”，或者启动参数添加 `-- --xiaopei-battle`。镜头自动移到小沛附近，点击“进行”推进十天，双方都使用当前设置中的模型服务。

当前18名武将全部出阵。蜀汉10将每人2000人；袁绍集团7将与孙策组成测试对手，每人2500人。双方各20000人，步弓骑配比70/20/10，携带45日粮。孙策归属只在测试中调整，原人物数据文件不修改。

部队预置在小沛至濮阳的道路上，彼此已可侦察，第一轮就能选择接战、继续行军、撤退等动作。不强制真实模型选择攻击。模型分别收到每名武将的性格、任务、有限情报与合法行动候选；实际战损仍由规则计算。

左上显示模型启用状态、累计调用/失败/回退次数。点击我方头像看详情与复盘，点击对方头像可以观察最近决策。测试视图显示双方主帅头像和实际位置，但模型仍使用战争模块的侦察情报，不获得测试观察者的全图权限。

测试保留当前战役的内存快照，并关闭战役自动保存；“结束测试，返回原战役”恢复快照。退出程序后默认加载原来的正式存档。接口与本机密钥配置继续保留。测试过程中按设置中的“重置”重新生成所有军队，需等待当前十日推进结束。

验证：`tests/xiaopei_battle_validation.gd` 检查18个不同武将、双方各2万人、双方独立决策、全部接战，以及退出后原战役恢复；加 `-- --capture` 捕获实际3D场景。自动验证使用测试代理，不调用用户真实服务。
