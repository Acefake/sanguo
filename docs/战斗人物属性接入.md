# 战斗人物属性接入

更新：2026-10-04。范围为现有战略道路交战、攻城与小沛六角战场。人物原始数值不变，五维总值不再叠加到子属性，避免重复计算。

## 已参与结算

| 属性 | 用途 |
| --- | --- |
| 带兵 | 动员上限、道路行军、军令组织与军队战力；统帅光环强度 |
| 布阵 | 战力、伤亡防护 |
| 水练 | 河流地区作战与道路行军 |
| 奇袭、智计 | 侧击、追击，与对手料敌和应变对抗；智计同时影响攻城准备、专长打分 |
| 治军 | 战力、防护、组织抗损与恢复、行军疲劳；统帅光环强度 |
| 沉着 | 弓兵发挥、士气抗损与恢复 |
| 料敌 | 侦察估计误差、反制战术；战略层守军估计沿用同一口径 |
| 应变 | 防护、反制战术、攻城准备、组织恢复 |
| 辩才 | 休整时鼓舞恢复士气 |
| 膂力、武艺 | 步兵攻击；武艺同时影响骑兵、专长打分 |
| 体魄 | 疲劳增长与休整恢复 |
| 骑术 | 骑兵攻击、道路机动、追击俘获 |
| 箭术 | 弓兵攻击 |
| 威仪、忠义 | 士气抗损；威仪也影响士气恢复；威仪≥80 扩大统帅光环范围一格，参与专长打分 |
| 名望 | 武圣威压的目标条件（目标名望至少80）；名望与威仪参与“立威”专长打分 |

计算有效属性：0—100正常收益，100—120的超出部分按30%计入，例如105折算101.5。人物卡仍显示原始105及蓝色超限状态。低属性不会获得与高属性相同的固定收益。

子属性的一般修正以50为基准，设上下限。兵力、兵种、训练、军备、地形、士气、组织、疲劳仍共同参与战斗，强将不能无视军队状态。合战分别累计各支部队的攻击，保留各自兵种和特性，不把一人的特性授予全军。

## 特性与人格

永久数值加成已在人物卡中体现，不再次叠加。额外场景效果包括：骑战骑兵攻击+3%；百步穿杨弓兵发挥+6%；穿插侧击+3%；乘隙追击追击+3%；运筹帷幄侧击筹划+6%；百战成军疲劳增长-6%；耐战交战疲劳-3%；远征统筹组织恢复+6%。险地用兵在山地、丘陵获得6%行动/攻击优势；精锐突击在训练达到80且主动攻击时提高5%攻击。后二者原文未规定百分比，此处是可调的原型平衡参数。

武圣：首次与高名望主将正面交锋，使敌部士气下降8；同一目标仅一次，侧击、追击与远射不触发。目标记录随军队存档保留。

小霸王：记录主动攻取中的击溃或攻城胜利。默认30日内下一次主动出征，道路首次接敌前机动提高8%，首次接敌士气冲击提高8%，触发一次即消费。溃败/覆没立即清空；守援、分队不会继承。胜利时间与触发状态存档保留。

默认离线AI继续使用风险承受、耐心，并加入决断、自制对主动行动和缺粮追击的倾向；冒进提高进攻风险倾向，多疑增加敌情未明时的侦察倾向。在线模型接收人物技能、人格与特性资料，但最终伤亡由本地公式结算。

2026-10-05 追加接入（见 [将领战场作用方案](将领战场作用方案.md)）：进攻合成（兵种发挥×指挥）收窄至 0.8–1.2、防御合成 0.9–1.1、将领总乘子 0.6–1.6 兜底；统帅光环按 (带兵+威仪+治军)/3 计算，威仪≥80 时范围 4 格，减轻范围内士气与组织损失、下调溃败阈值；规则生成专长每名将领至多一个（临阵稳军、乘势突击、设伏、断后、激将、立威），带武圣者不再触发“立威”，避免重复。军令书（意图/撤退线/冒险许可/汇报频率）与违令判定使用人格 14 轴，关系（同袍/猜忌/宿怨）由记仇、猜疑、容人、忠义推导，不写回人物卡。非玩家势力的战略评估只使用本方侦察口径的守军估计。

军队详情显示将领步弓骑攻击修正及休整恢复。旧存档加载时补齐特性，不修改军队已有兵力和技能。

## 现有模型边界

这是部队级战斗。刀术、枪术的“指定个人兵器伤害”、护主的“替目标受伤”仍无对应玩法，未强行改为全军伤害加成。2026-10-05 已接入三合制单挑及将领负伤、战后休养，单挑不直接扣兵或造成将领阵亡。小沛战场使用共享全局格网的真实地形，保留一格一日；水练兼容浅滩，险地适应沿用区域与格子地形管道。六种军团主阵、变阵成本和战况反馈见 [扩展实现记录](战斗系统扩展实现-2026-10-05.md)。卧龙的多系统并行处理惩罚尚无对应负担模型，只保留卡内已计入的永久加成。内政、外交特性不在本次接入范围。
