# 旬制时间推进首版

参考《三国志14》官方说明书的下令、进行、报告阶段：一旬十日，进行阶段部队同时行动，支持三档速度。

来源：https://www.gamecity.com.tw/manual/sangokushi14/3300.html 与 https://www.gamecity.ne.jp/manual/sangokushi14-pk/ce/jp/3200.html 。这说明的是公开玩法，并非反编译得到的原作内核。

点击“进行十日”或在3D地图按空格开始，每次固定推进十个游戏日：1→11、18→28、23→次月3；从旬中开始也执行完整十天。所有军队共享一个推进时钟，日期旁显示阶段、旬和百分比。

进行中按钮变成“暂停”，再次点击或按空格立即冻结移动和动作，按钮变成“继续”。三档速度为1×、2×、4×，同时影响位置和动作播放。暂停保留当前进行阶段，继续后不重复结算已完成的天数；进行阶段的下令限制沿用现有 busy 保护。AI 请求正在等待时暂停会冻结接下来的画面，但不会取消已经发出的请求。

十天执行结束后停止推进并打开军报，重要军情保留但不提前截断本次执行，只在整个推进结束时保存一次。默认每个游戏日的画面播放2秒，所以十天约20秒（不含模型请求等待）；2×约10秒，4×约5秒。这些时长是项目设置，非原作测量值。

当前规则仍按日计算，位置和动作在日内插值播放；没有实现原作的完整六角格寻路、命令书、内政旬结算和采配系统。保留“推进本月”用于已有操作流程。

验证：`tests/war/campaign/war_turn_time_validation.gd` 检查旬边界、旬中开始、跨月、阶段与保存次数；`tools/capture/capture_army_world_3d.gd` 检查真实3D移动中间位置、战斗帧、立即暂停冻结和撤退归营。
