# 武将资讯与情报

大地图顶部「武将」打开情报一览；城内官府「人事 → 武将情报」和酒肆「武将情报」也可打开。点击情报行进入详情，底部「情报一览」切换列表与详情，「资料来源」打开当前人物的 Notion 原页，返回或 Esc 关闭。

详情顶部为基本、人格、关系、列传；情报列表为基本、个人、名声、关系、属性、特性。搜索支持姓名和字，可筛选集团；基本列表的五维表头可切换升降序。

基本页按用户截图布置左侧名单、中部立绘与姓名、右侧雷达图和能力条、人格数值和岗位适性，不再展示地图、身份及未设计的名声字段。基本信息的横向、纵向分割线统一移除。雷达图和能力条采用 Notion 的 120 上限。技能页的 25 项子属性按五个能力分列，名称与数值上排、原生矩形细进度条下排。特性采用原图集的六边标签，仅显示名字，悬停显示完整介绍；人格已并入基本页，显示三列原生矩形进度条；岗位显示完整核心、次选、不宜岗位及说明。详情和表格共用一份数据。
