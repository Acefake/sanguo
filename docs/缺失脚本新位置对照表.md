## 3. 挪完之后

1. 每个文件旁边如果有 `.gd.uid`，一起挪，uid 不用改。
2. 这些本地文件里 preload 的仓库脚本也搬了家。对挪好的文件跑一次路径改写：

   ```
   python tools/migrate_paths.py scripts/war/battle/city_defense.gd scripts/agents/unit_brain.gd （把上面挪过的文件都列上）
   ```

   完整的旧→新对照在 [目录迁移-2026-10-21.tsv](目录迁移-2026-10-21.tsv)。脚本只改写整段 `res://` 路径，可以重复跑。
3. 用 Godot 打开一次项目，让编辑器刷新文件缓存；再跑 `godot --headless --script res://tests/run_battle_suite.gd` 确认回归。
